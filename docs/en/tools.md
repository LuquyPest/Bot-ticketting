# Portainer, Coolify, Unraid, CasaOS

Already running your services from an interface? The [`deploy/`](https://github.com/LuquyPest/Bot-ticketting/tree/main/deploy) folder of the repository holds a **standalone** compose file: it needs no other file from the repository, you just paste it into your tool and fill in the variables.

| File | For |
|---|---|
| [`deploy/docker-compose.standalone.yml`](https://github.com/LuquyPest/Bot-ticketting/blob/main/deploy/docker-compose.standalone.yml) | Portainer, Unraid (Compose Manager), Dockge, Synology Container Manager, any tool that takes a compose file |
| [`deploy/coolify/docker-compose.yml`](https://github.com/LuquyPest/Bot-ticketting/blob/main/deploy/coolify/docker-compose.yml) | Coolify: domain and passwords generated by Coolify |
| [`deploy/casaos/docker-compose.yml`](https://github.com/LuquyPest/Bot-ticketting/blob/main/deploy/casaos/docker-compose.yml) | CasaOS: the standalone file with the app details |

::: info Before you start
You need the **Discord application** (Application ID, token, Client Secret): [step 3 of the installation](./installation#step-3-—-create-the-bot-on-discord). Discord only allows signing in to the dashboard over **HTTPS**: the dashboard must go through a reverse proxy (Nginx Proxy Manager, Traefik, Caddy, SWAG…), except with Coolify which handles it.
:::

## The variables

Generate each secret with `openssl rand -hex 32` (64 hexadecimal characters), or with a password generator for the three passwords.

| Variable | Value |
|---|---|
| `DISCORD_TOKEN`, `DISCORD_CLIENT_ID`, `DISCORD_CLIENT_SECRET` | Discord developer portal |
| `PUBLIC_URL` | HTTPS address of the dashboard, for example `https://tickets.example.com` |
| `DB_ROOT_PASSWORD`, `DB_PASSWORD`, `REDIS_PASSWORD` | Three different passwords |
| `SESSION_SECRET` | `openssl rand -hex 32` |
| `ENCRYPTION_KEY` | `openssl rand -hex 32` — **keep it off the server**: without it, transcripts are unreadable |
| `WEB_PORT` | Port of the dashboard on the machine (3000 by default), which your reverse proxy points to |
| `TICKETBOT_VERSION` | `latest`, or a precise version |

Then, in the Discord portal, add `PUBLIC_URL` + `/api/auth/discord/callback` to the OAuth2 *Redirects*.

## Portainer

1. **Stacks → Add stack**, name it `ticketbot`.
2. **Web editor**: paste `deploy/docker-compose.standalone.yml`.
3. **Environment variables → Advanced mode**: paste the variables (one per line, `NAME=value`).
4. **Deploy the stack**, then point your reverse proxy to port `3000` of the machine.

## Unraid

With the **Docker Compose Manager** plugin (Community Applications):

1. **Docker → Compose → Add new stack**, name it `ticketbot`.
2. **Edit stack → Compose file**: paste `deploy/docker-compose.standalone.yml`.
3. **Edit stack → Env file**: the variables.
4. **Compose up**, then add the dashboard to your reverse proxy (SWAG, Nginx Proxy Manager…).

## Coolify

1. **Project → New resource → Docker Compose Empty**, paste `deploy/coolify/docker-compose.yml`.
2. Coolify creates the domain (`SERVICE_FQDN_BOT`) and the passwords. In **Environment Variables**, fill in `DISCORD_TOKEN`, `DISCORD_CLIENT_ID`, `DISCORD_CLIENT_SECRET` and `ENCRYPTION_KEY`.
3. **Deploy**. The domain shown by Coolify is the one to use in the Discord portal (`/api/auth/discord/callback`).

## CasaOS

1. **App Store → Custom install → Import → Docker Compose**, paste `deploy/casaos/docker-compose.yml`.
2. Fill in the environment variables of the `bot`, `db` and `redis` containers.
3. **Install**, then put the dashboard behind HTTPS (Discord requires it).

## Differences with the full install

These files hold the database, Redis and the bot. They do **not** include the optional services of the [full install](./installation): nightly encrypted backups, the copy off the server and the update button. Back up the database volume with your platform's tools (or move to the full install to get them), and update by redeploying the stack: the new image is pulled and migrations apply at start-up.

::: tip Tested, not everywhere
The standalone file is tested with Docker Compose. The screens of these tools change over time: if one does not match, [open an issue](https://github.com/LuquyPest/Bot-ticketting/issues) with what you see.
:::
