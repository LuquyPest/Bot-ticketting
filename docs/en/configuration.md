# Configuration

Everything is set in the **`.env`** file at the root of the repository, created by `scripts/setup.sh`. Each variable is also commented in [`.env.example`](https://github.com/LuquyPest/datick/blob/main/.env.example). The rest — roles, categories, messages, deadlines, webhooks… — is set from the **dashboard** and lives in the database.

::: tip After a change
`docker compose up -d` is enough: only the container concerned restarts.
:::

## Discord and public address

| Variable | Role |
|---|---|
| `DISCORD_TOKEN` | Optional: bot token (developer portal → *Bot* → *Reset Token*). Without it, no bot: dashboard, e-mail and API only |
| `DISCORD_CLIENT_ID` | Application ID (*General Information*) |
| `DISCORD_CLIENT_SECRET` | Optional: OAuth2 secret (*OAuth2* → *Client Secret*). With `DISCORD_CLIENT_ID`, turns on the Discord sign-in |
| `PUBLIC_HOST` | Domain of the dashboard, without `https://` (`tickets.example.com`) |
| `PUBLIC_URL` | Full public address, in `https://`, without a trailing slash |
| `DISCORD_CALLBACK_URL` | Optional: by default `PUBLIC_URL` + `/api/auth/discord/callback`, the address to register in the Discord portal |
| `INSTALL_TOKEN` | Token to create the first owner on `/installation`, without Discord (`setup.sh` generates it); without it, a token is printed in the logs at start-up |

## HTTPS and containers

| Variable | Role |
|---|---|
| `COMPOSE_FILE` | Compose files in use, separated by `:`. Base: `docker-compose.yml`; add `docker-compose.caddy.yml` (bundled Caddy, Let's Encrypt) **or** `docker-compose.traefik.yml` (your Traefik), `docker-compose.backup.yml` (backups), `docker-compose.offsite.yml` (copy off the server) and `docker-compose.updater.yml` (update button) |
| `ACME_EMAIL` | E-mail for Let's Encrypt (Caddy) |
| `DATICK_VERSION` | Image version: `latest`, or a precise version (`v3.1.0`) to update only when you decide (the former name `TICKETBOT_VERSION` is still read) |
| `BIND_ADDRESS` / `WEB_PORT` | Without Caddy or Traefik: address and port published on the machine (`127.0.0.1:3000` by default, to put behind your own proxy) |
| `TRUST_PROXY_HOPS` | Number of proxies in front of the application (1; 2 behind Cloudflare), to know the real IP address of visitors |
| `TRUSTED_PROXY_HOST` | Name of the proxy whose `X-Forwarded-For` header is trusted (set on its own by the Caddy and Traefik files). Empty: the header is only trusted from a local or private address |
| `TZ` | Time zone (time of the backups) |

## Secrets

Generated by `setup.sh` (`openssl rand -hex 32` by hand). **Keep a copy of `.env` off the server**: without `ENCRYPTION_KEY`, the transcripts and the 2FA secrets are unreadable; without `BACKUP_KEY`, the backups too.

| Variable | Role |
|---|---|
| `DB_ROOT_PASSWORD` | Administrator password of MariaDB — never passed to the bot |
| `DB_PASSWORD` | Password of the `botuser` account, limited to the bot's databases |
| `REDIS_PASSWORD` | Redis password |
| `SESSION_SECRET` | Key of the dashboard sessions (at least 32 characters) |
| `ENCRYPTION_KEY` | AES-256 key of the 2FA secrets and transcripts, 64 hexadecimal characters ([rotation](./security#rotating-the-encryption-key)) |
| `BACKUP_KEY` | Encryption key of the [backups](./backups) |
| `VAPID_PUBLIC_KEY` / `VAPID_PRIVATE_KEY` / `VAPID_CONTACT` | Push notifications of the dashboard (optional) |

## Instance

| Variable | Role |
|---|---|
| `OWNER_IDS` | Discord accounts that co-own the instance, besides the owner of the application (IDs separated by commas) |
| `ALLOWED_GUILDS` | If set, only these Discord servers are accepted: the bot leaves any other server at once |
| `PRIVACY_URL` | Your own privacy page (by default, the built-in `/confidentialite` page) |
| `CONTACT_EMAIL` | Contact e-mail shown on the privacy page |
| `TRANSCRIPT_RETENTION_DAYS` | How long transcripts are kept, in days (empty: forever) |
| `BACKUP_TIME` / `BACKUP_KEEP_DAYS` | Time of the nightly backup (03:00) and how long archives are kept (30 days) |
| `BACKUP_VERIFY` | Automatic check of the latest archive: `off` (default), `weekly` or `daily` — [Backups](./backups#automatic-check) |
| `BACKUP_REMOTE` | rclone destination of the off-site copy (`b2:my-bucket/ticketbot`), with `docker-compose.offsite.yml` |
| `EMAIL_ALLOW_PRIVATE_HOSTS` | `true`: allows an IMAP/SMTP server on your local network for [tickets by e-mail](./integrations#tickets-by-e-mail) |
| `UPDATE_CHECK` | `off`: never check GitHub for new versions |
| `UPDATER_TOKEN` / `PROJECT_DIR` | « Update » button: token shared with the `updater` service and absolute path of the install folder — [Updates](./updates#update-from-the-dashboard) |

## Database

By default `db`, `3306`, `botuser`, `ticketbot_global`: the names from the compose file. Only change them for an external database: `DB_HOST`, `DB_PORT`, `DB_USER`, `DB_NAME`.

## Rare settings: `config.json`

A few settings have no variable. Put them in a `config.json` (template: [`config.example.json`](https://github.com/LuquyPest/datick/blob/main/config.example.json)) and mount it into the container (commented lines of `docker-compose.yml`). Environment variables always win over it.

| Key | Default | Role |
|---|---|---|
| `retention.loginLogsDays` | 90 | How long dashboard sign-ins (IP addresses) are kept |
| `retention.errorLogsDays` | 30 | How long the error log is kept |
| `retention.auditLogDays` | 365 | How long each server's log is kept |
| `retention.sessionsDays` | 7 | How long session tracking is kept |
| `retention.instanceAuditDays` | 730 | How long the instance log is kept |
| `rateLimits.apiPerMinute` | 200 | Requests per minute and per address on the API |
| `dashboard.previousEncryptionKeys` | `[]` | Old keys accepted for reading during a rotation |
| `database.tenantConnectionLimit` | 5 | MariaDB connections per Discord server (raise it for a very busy server) |
| `webEnabled` | `true` | `false`: bot only, no dashboard |
